# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-09-24

## Context
Decisions for this project were made in a planning ("grilling") session. Future contributors (including future me, and AI assistants) need to know *why* things are the way they are.

## Decision
Record each significant decision as a short ADR in `docs/decisions/`, numbered sequentially, using the format Context / Decision / Consequences. Superseded ADRs are kept and marked `Superseded by NNNN`.

## Consequences
- Changing a recorded decision means writing a new ADR, not silently editing code.
- Domain vocabulary lives separately in `CONTEXT.md`.
